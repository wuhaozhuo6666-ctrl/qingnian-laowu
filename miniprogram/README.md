# 青年老吴原木家具微信小程序

这套小程序与网站后台共用产品、案例和联系人资料。产品页和选品清单已经配置微信原生分享卡片，顾客点卡片可直接进入对应产品或共享清单。

## 正式发布前需要店主完成

1. 在微信公众平台注册小程序，名称填写“青年老吴原木家具”。
2. 复制微信生成的 AppID，替换 `project.config.json` 中的 `touristappid`。
3. 在“小程序后台 → 开发管理 → 开发设置 → 服务器域名”中，把 `https://qingnian-laowu.netlify.app` 添加为 request、download 合法域名。
4. 使用微信开发者工具导入本目录，真机预览产品图片、选品清单、联系人和分享卡片。
5. 上传代码并提交微信审核；审核通过后发布。

> 小程序名称和 AppID 不是一回事。名称可以是中文，AppID 是微信生成的专属编号。没有正式 AppID 和微信审核，普通网页无法发送真正的微信小程序卡片，也无法从代码层彻底取消微信对外部链接的风险提示。
